# From Zero to Hero — Full System Audit

**Audit date:** 2026-10-03  
**Default table:** 4 players  
**Supported table:** 4–6 players  
**Scope:** Level-0 rules, fairness, development math, Upbringing Lean, competition procedure, scrapbook ledger, village continuity, graduation, 2014/2024 boundary, and table-run adventure readiness.

## Executive result

**Status after this pass: playable origin-adventure candidate, not yet Level-1 conversion complete.**

The core design now has a coherent contract:

- all six ability scores start at **9**;
- each character chooses one balanced **2 Favored / 2 Neutral / 2 Challenging** Upbringing Lean;
- each of seven yearly chapters contains exactly three shared Growth Beats;
- every player receives one Development Check in every Growth Beat;
- success/failure always preserves the baseline development budget;
- the completed Level-0 array is guaranteed to reach at least **27 point-buy value** and can never exceed **30**;
- the scrapbook is the authoritative development history;
- competition placement is memorable but cannot secretly increase the development budget;
- graduation keepsakes are commemorative only;
- all Level-1 mechanics remain edition-isolated and must come from certified 2014 or 2024 sources.

The largest weakness found in this audit was **competition fairness**. The initial competition library allowed too many abilities in each contest, meaning most class-shaped upbringing profiles could find a Favored lane in nearly every contest. That made strengths and weaknesses less meaningful.

This pass fixes that with the **Hearthcross Six**: exactly one core contest for each of STR, DEX, CON, INT, WIS, and CHA.

Because every Upbringing Lean partitions the six abilities into exactly two Favored, two Neutral, and two Challenging lanes, the six-contest slate mathematically guarantees every profile exactly:

- **2 Favored competitions**
- **2 Neutral competitions**
- **2 Challenging competitions**

No class-shaped upbringing receives more favorable competition lanes than another.

## 1. Starting character audit

### Pass

Every character begins:

- STR 9
- DEX 9
- CON 9
- INT 9
- WIS 9
- CHA 9

Upbringing Lean does not alter these scores.

The six 9s represent a 5E point-buy value of 6 under the normal 8–15 point-buy cost table.

No class, subclass, class feature, spellcasting, armor/weapon proficiency package, feat, or adult adventuring equipment is granted at Level 0.

## 2. Development-budget audit

### Pass

There are exactly **21 base Development Opportunities**:

- 7 yearly chapters
- 3 Growth Beats per chapter
- 1 Development Check per player per Growth Beat

Each ordinary outcome preserves one baseline Development Point:

| Outcome | Growth |
| --- | --- |
| Success | +1 Flexible DP |
| Failure | +1 off-path Lesson DP |
| Critical success | +2 Flexible DP total |
| Critical failure | +1 off-path Lesson DP + at most one 1-for-1 invested-point redirect |

The baseline proof remains:

**6 starting point-buy value + 21 baseline development = 27 minimum.**

Critical failures redirect growth but do not destroy earned development.

Critical successes can create bonus development, but the final Level-0 array is hard-capped at **30 point-buy value**.

## 3. Ability-score cap audit

### Pass

Pre-origin ability scores cannot exceed **15**.

The development wallet follows the normal point-buy cost slope from 9 through 15:

- 9→10 = 1
- 10→11 = 1
- 11→12 = 1
- 12→13 = 1
- 13→14 = 2
- 14→15 = 2

The interface blocks a Development Point investment if it would make the total base-array point-buy value exceed 30.

## 4. Upbringing Lean fairness audit

### Pass with one ongoing content requirement

There are exactly twelve class-shaped presets:

- Barbarian
- Bard
- Cleric
- Druid
- Fighter
- Monk
- Paladin
- Ranger
- Rogue
- Sorcerer
- Warlock
- Wizard

Every profile contains exactly:

- 2 Favored abilities — Upbringing Advantage
- 2 Neutral abilities — normal roll
- 2 Challenging abilities — Upbringing Disadvantage

No profile receives a third Favored ability or fewer than two Challenging abilities.

At age 12, ability 9 (-1), DC 15:

- Favored / Advantage: **43.75%** success
- Neutral: **25%**
- Challenging / Disadvantage: **6.25%**

This is intentionally a strong childhood-exposure signal before the ability scores diverge.

### Character Advantage interaction

Normal 5E-style cancellation is used:

- Favored + Character Advantage = Advantage
- Neutral + Character Advantage = Advantage
- Challenging + Character Advantage = Normal
- any Advantage + any Disadvantage = Normal
- multiple Advantage sources do not stack
- multiple Disadvantage sources do not stack

Upbringing Disadvantage is not a punishment for weak roleplay. It is fixed history.

The profile locks after the first resolved Growth Beat.

### Ongoing requirement

Adventure content must continue to rotate what kinds of abilities matter. The 2/2/2 profile math alone is not enough if every important scene tests only the same ability families.

## 5. Competition audit

### Prior issue: fixed in this pass

The initial competition list was mechanically too broad. For example, several contests accepted three or four different abilities, which meant nearly every Upbringing Lean had access to a Favored ability in nearly every contest.

That was fair in the sense that everybody could optimize, but it defeated the purpose of having upbringing strengths and weaknesses.

### New core standard: Hearthcross Six

The six core development-facing childhood contests are now:

| Ability | Contest |
| --- | --- |
| STR | Sack Haul |
| DEX | Rat Race |
| CON | Pie-Eating Contest |
| INT | Riddle Table |
| WIS | Hearthcross Scavenger Hunt |
| CHA | Lantern Presentation |

All contestants use the same primary ability for a given core contest.

Placement is determined by:

1. final check total;
2. higher kept d20 on a tie;
3. one story-only d20 tiebreak if a podium tie remains.

Placement itself grants no Development Points.

Every player receives a scrapbook result card:

- 1st — podium
- 2nd — podium
- 3rd — podium
- 4th — unique consolation/mishap
- 5th — unique consolation/mishap
- 6th — unique consolation/mishap

Humorous titles may exaggerate, but the official result and field size remain recorded.

Optional side contests may exist, but they may not silently add development outside the 21-opportunity budget.

## 6. Critical-result fairness audit

### Pass

The critical system is explicitly Level-0 house rule.

The normal check resolves first:

**d20 + modifier vs DC**

Then the Level-0 outcome tier is assigned.

Natural 20 does not automatically turn an impossible total into success. Natural 1 does not independently override the total; in the current DC/score ranges it will ordinarily fail anyway.

Because Advantage and Disadvantage change natural-20/natural-1 frequency, upbringing also changes the chance of extraordinary memories. This is acceptable because every profile has the same total number of Favored and Challenging lanes across a balanced slate, and the final array remains bounded 27–30.

## 7. Shared-table fairness audit

### Pass for 4–6 players

A Growth Beat is a shared situation, not one party check.

Every player gets one Development Check before the beat closes.

For the default four-player table, spotlight order rotates from beat to beat. Success by Player 1 can improve the fiction but cannot erase Players 2–4's opportunities.

Five- and six-player scaling adds additional distinct tasks or simultaneous fronts rather than increasing DCs.

This prevents larger tables from receiving harder math merely because more players attended.

## 8. Failure audit

### Pass

Ordinary failure:

- awards one baseline Development Point as an off-path Lesson;
- changes the fiction;
- creates a cost, embarrassment, delay, damaged relationship, lost resource, or worse position;
- does not stop required progression.

Critical failure:

- preserves baseline development;
- adds the off-path lesson;
- can redirect at most one already-invested point;
- may create a scar, lasting embarrassment, lost object, relationship complication, or altered village state;
- does not make child death the default consequence.

## 9. Scrapbook audit

### Pass

The scrapbook is now the authoritative development ledger.

Every resolved Growth Beat creates exactly one Development Card.

A completed origin therefore has **21 mechanical Development Cards** before optional story-only memory cards are counted.

Each mechanical card records the actual development result. It does not award a second copy of that result.

The final character sheet is the summary; the scrapbook explains why the summary looks the way it does.

Extra relationship, Yearbook, reputation, award, travel, and comedy cards remain story-only unless they are also the Development Card for a declared Growth Beat.

## 10. Village-continuity audit

### Pass

Hearthcross contains recurring:

- guardians/families;
- friends;
- rivals;
- mentors;
- authority figures;
- workers and shopkeepers;
- evolving locations;
- a village mystery.

Between-year interludes and Yearbook entries make time passing visible.

Earlier choices return during the Long Storm and Last Spring Dance.

The final crisis is designed to use the party's accumulated relationships, repairs, saved locations, mentor history, and scrapbook memories rather than ignoring six years of play.

## 11. Life-stage / danger audit

### Pass

Ages 12–15 default to:

- chores;
- festivals;
- family work;
- competitions;
- social problems;
- apprenticeship;
- ordinary accidents.

Age 16 introduces unsupervised travel.

Age 17 introduces the first serious community emergency.

Age 18 contains the true origin crisis.

The escalation is based on life stage rather than a need to put a larger monster in every session.

## 12. RAW / house-rule boundary audit

### Pass

The following are explicitly house rule and remain Level-0-only:

- Upbringing Lean Advantage/Disadvantage;
- Level-0 critical success/failure development tiers;
- Development Points;
- Lesson Points;
- critical-failure development redirect;
- 27–30 Level-0 graduation envelope;
- scrapbook as development ledger.

At Level 1, these stop granting mechanics.

The chosen 2014 or 2024 ruleset controls:

- race/species;
- background;
- class;
- subclass timing;
- HP;
- proficiency bonus;
- saving throw proficiencies;
- skill/tool/weapon/armor proficiencies;
- spells;
- feats;
- equipment;
- later advancement.

No edition mixing is permitted inside one character.

## 13. Graduation audit

### Pass with one known incomplete feature

Graduation requires:

- all seven chapters complete;
- all 21 base Development Opportunities resolved;
- Lesson Points settled;
- final base array point-buy value 27–30;
- no pre-origin score above 15;
- selected 2014 or 2024 path.

The certificate and Origin Chronicle are commemorative only.

### Known incomplete feature

The site does **not yet generate the final certified Level-1 class package** from the completed origin.

Therefore graduation wording must remain:

**ready for certified Level-1 creation**

It must not claim a Level-1 class until the reusable certified Level-1 packs are wired.

## 14. Adventure-readiness audit

### Prior gap: fixed in this pass

Before this pass, Zero to Hero was primarily a rules engine and player growth interface.

The new DM-facing adventure package, **From Zero to Hero: The Hearthcross Years**, adds:

- default 4-player procedure;
- 4–6 scaling;
- seven session/chapter openings;
- 21 DM-run Growth Beat scenes;
- 2–4 sentence read-aloud;
- explicit run order;
- spotlight rotation;
- direct link to the authoritative Growth Beat DC/approaches/outcomes;
- scrapbook prompts;
- persistent consequences;
- Yearbook transitions;
- final Watchstone crisis;
- graduation checklist.

The player Growth Sheet remains mechanically authoritative. The DM adventure runner owns pacing and presentation.

## Release blockers remaining

Zero to Hero should not be called fully finished until:

1. the new DM adventure validator is green;
2. the competition fairness validator proves one core contest per ability;
3. the DM runner and player sheet cross-link correctly;
4. post-merge Pages deploy succeeds;
5. certified Level-1 graduation packs are wired for the intended 2014/2024 choices.

## Audit conclusion

The system is internally coherent after this pass.

The design now produces **equal starting numbers, unequal but balanced childhood odds, bounded mechanical growth, meaningful failure, a visible scrapbook history, fair competition exposure, and a real seven-chapter adventure that turns those systems into play**.

The remaining major mechanical milestone is certified Level-1 conversion.
