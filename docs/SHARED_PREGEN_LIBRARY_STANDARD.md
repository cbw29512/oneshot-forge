# Shared Pregen Library Standard

## Two separate libraries

99¢ One-Shots maintains **two independent pregen libraries**:

- **2014 rules library**
- **2024 rules library**

The same recurring hero identity may appear in both editions, but the mechanics are edition-native. Never treat a 2024 sheet as an update to the 2014 mechanical sheet or vice versa.

Shared across editions where appropriate:
- character name and identity
- portrait/art direction
- broad personality and role
- broad class fantasy

Edition-specific:
- class progression
- subclass timing and features
- ability-score/feat choices
- spell lists and spell text
- weapon/mastery rules
- species/background mechanics
- proficiency calculations
- equipment legality
- magic-item progression
- final printed sheet

Same-named spells, features, subclasses, feats, and items must be checked independently.

## Progression rule

Within each edition, a character is persistent from level to level.

Level N+1 MUST be advanced from Level N.

Never rebuild a later level from scratch.

## Subclass branching

At the edition's subclass-selection point, fork the existing base character into one persistent branch for each supported subclass.

Example:

```
2014 Brann — Fighter
  shared legal base
    ├─ Champion → 20
    ├─ Battle Master → 20
    └─ Eldritch Knight → 20

2024 Brann — Fighter
  shared legal base
    ├─ Champion → 20
    ├─ Battle Master → 20
    └─ Eldritch Knight → 20
```

The two trees are certified independently.

## Magic items

Magic-item assignment is edition-specific and must follow that edition's higher-level starting guidance.

### 2014

Use the 2014 DMG higher-level starting-equipment guidance as the baseline for 2014 pregens.

Do not automatically reuse the 2024 item counts.

### 2024

Use the 2024 higher-level starting-equipment guidance for 2024 pregens.

Do not automatically reuse the 2014 item counts.

## Item-fit requirements

Every assigned item must:

1. be legal and usable by the character;
2. support the actual build;
3. reinforce primary weapon, armor, spellcasting, healing, defense, mobility, or signature utility;
4. avoid dead or redundant upgrades;
5. respect attunement limits;
6. leave reasonable room for treasure found during a one-shot;
7. favor one-shot-useful gear over downtime/campaign-economy items;
8. use distributable rules text or original project wording in customer-facing material.

Examples:
- Fighter: primary weapon and/or shield/armor first.
- Barbarian: primary heavy weapon, rage-compatible defense/mobility.
- Rogue: finesse/ranged weapon, stealth/mobility.
- Ranger: primary ranged weapon, exploration/combat support.
- Cleric: shield/armor where legal, healing/support focus, restorative consumables.
- Moon Druid: Wild-Shape-compatible or spellcasting/defensive gear rather than irrelevant weapon upgrades.
- Wizard/Sorcerer/Warlock: wand/staff/rod/focus, defense, spellcasting support.
- Consumables such as healing potions supplement permanent gear rather than replace core progression.

## One-shot selection

An adventure declares:
- rules edition;
- adventure level;
- recommended party;
- optional alternates.

The storefront then exposes the matching edition + level pool only.


## Adventure edition binding

Edition selection happens at the **adventure level**, before pregens are shown.

A released one-shot must support both 2014 and 2024 as separate certified play modes.

When the GM chooses **2014**:
- load the 2014 adventure rules package;
- load only 2014 monster/NPC/stat/rules references;
- load only 2014 spells, features, feats, equipment, and magic-item rules;
- show only the matching 2014 pregen pool at the adventure's level;
- print only 2014-compatible character sheets and references.

When the GM chooses **2024**:
- load the 2024 adventure rules package;
- load only 2024 monster/NPC/stat/rules references;
- load only 2024 spells, features, feats, equipment, and magic-item rules;
- show only the matching 2024 pregen pool at the adventure's level;
- print only 2024-compatible character sheets and references.

### No mixed-edition state

The runner MUST NOT permit:
- a 2014 adventure with 2024 pregens;
- a 2024 adventure with 2014 pregens;
- same-name spells/features/items silently crossing editions;
- cached character selections from one edition appearing in the other.

Changing edition must refresh all edition-bound adventure and character data.

### Paid-release invariant

A one-shot is not sellable until **both edition packages are certified**:
- 2014 adventure package ready;
- 2014 level-matched pregen pool ready;
- 2024 adventure package ready;
- 2024 level-matched pregen pool ready.

A product may be playtested in one edition before the other is finished, but it cannot be marked as the finished paid product until both pass their release gates.
