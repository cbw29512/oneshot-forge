# The Quiet Seals — how the campaign is a stack of one-shots

Hub: **Hearthford**. Ten notables. Same six PCs.

1. Mayor Cald Wren sends them to Briar Glen. That night is *The Lantern Below*. Complete one-shot.
2. They come back. Mark Wren Helped. Pick another notable. That night is also a complete one-shot. Any order.
3. Relationships are 0–3 (Stranger / Helped / Trusted / Bound). Write them on `campaign.html`.
4. The mayor’s last night is never locked. Four Trusted notables = the town helps. Skip everyone = still finish, bleed more.

Data: `data/campaigns/quiet-seals.campaign.json`.  
Do not generate the eight middle nights as filler. Author them one at a time to `docs/QUALITY.md`. Next: *The Well That Would Not Dry* (Oda Flint).
