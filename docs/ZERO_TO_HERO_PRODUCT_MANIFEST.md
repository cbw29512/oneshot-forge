# From Zero to Hero: The Hearthcross Years — Product Manifest

**Product status:** authored digital boxed-set candidate  
**Default table:** 1 DM + 4 players  
**Supported table:** 1 DM + 4–6 players  
**Campaign length:** 7 sessions/chapters, ages 12–18  
**Core promise:** play through character creation; every important win and loss becomes part of the character's scrapbook and final Level-1 origin.

This manifest is a release gate. A paid package is incomplete if a required item below is missing, stale, contradictory, or requires the customer to reconstruct developer URLs.

## 1. Open this first

### START HERE / Table Setup
Required contents:
- one-screen product premise;
- expected number of sessions and time per session;
- supported player count;
- what the DM needs;
- what each player needs;
- 10-minute first-session setup;
- print checklist;
- digital-run links;
- rules boundary: Level-0 homebrew → locked 2014/2024 RAW handoff;

## 3. Player packet

Each player needs:
- Level-0 Growing-Up Sheet;
- character journal / Yearbook;
- scrapbook card sheets;
- competition/trophy cards;
- graduation certificate + Origin Chronicle;
- access to one starter child or a blank Level-0 shell.

### Starter cast
Default four:
1. Tod Hale — Human — Fighter-shaped upbringing
2. Merlon Quill — Elf — INT/CHA caster-shaped upbringing
3. Halley Brindle — Halfling — Rogue-shaped upbringing
4. Mira Alder — Dwarf — Cleric-shaped upbringing

Optional fifth/sixth:
5. Fen Bell — Human — Ranger-shaped upbringing
6. Lark Cask — Elf — Bard-shaped upbringing

All starter children:
- begin with STR/DEX/CON/INT/WIS/CHA 9;
- have fixed race/species identity;
- have no class;
- have no Level-1 background/proficiency/spell/feat/equipment package;
- use a balanced 2 Favored / 2 Neutral / 2 Challenging Upbringing Lean;
- may graduate into any legal class permitted by the selected edition.

## 9. Buyer-experience release test

A stranger who buys the package must be able to answer without developer knowledge:
1. What is this?
2. How many people play?
3. How long is it?
4. What do I print?
5. What does the DM read first?
6. What does each player receive?
7. How do I use a starter character?
8. How do I make my own Level-0 child?
9. How do Upbringing Advantage/Disadvantage work?
10. What happens on success/failure/critical results?
11. How do competition placements work?
12. Where do scrapbook cards go?
13. What is on the player map vs DM map?
14. What must I record between years?
15. How do I graduate to Level 1?
16. Which rules are homebrew?
17. Which rules must come from 2014/2024 RAW/SRD?
18. What should I do if a player fails?
19. What should I do if the party misses a clue?
20. Where do I resume next session?

If any answer requires searching source code, the package is not ready.
